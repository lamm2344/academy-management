---
name: Attendance and grades
description: Product rule for the academy's grade-entry summary and separate attendance records.
---

The user wants the grade summary to omit the attendance column. Attendance should remain managed separately from exam and component-grade entry.

**Why:** The user explicitly asked to keep the summary table but remove its attendance column.

**How to apply:** When changing the score-entry UI, do not conflate attendance with the grade columns. Preserve existing attendance data unless the user explicitly asks to remove it.
